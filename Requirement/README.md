OrangeHRM Manual Testing Project
Project Overview
This project focuses on Manual Testing of the OrangeHRM Demo Application.

The objective of this project is to understand the application, identify important modules, create test scenarios, write test cases, execute them, report bugs, and later automate selected test cases using Playwright.
